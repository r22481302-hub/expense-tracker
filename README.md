# Expense Tracker

A console-based Expense Tracker built using **Python and MySQL**.

## Features
- Add expenses
- View all expenses
- Search by category
- Monthly expense summary
- Delete expenses
- MySQL database storage

## Tech Stack
- Python
- MySQL
- SQL
- mysql-connector-python

## How to Run
1. Install Python and MySQL.
2. Run `database.sql` in MySQL Workbench.
3. Install dependency:
   `pip install -r requirements.txt`
4. In `expense_tracker.py`, replace `YOUR_MYSQL_PASSWORD` with your local MySQL password. Do not upload your real password to a public repository.
5. Run:
   `python expense_tracker.py`
